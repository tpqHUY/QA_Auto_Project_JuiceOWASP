# Architecture Decision Records (ADRs)

Short documents capturing a significant design decision, its context, and its
consequences. They explain _why_ the framework is built the way it is — the
reasoning that code and commit messages don't capture on their own.

Format: [Michael Nygard's ADR template](https://github.com/joelparkerhenderson/architecture-decision-record).
